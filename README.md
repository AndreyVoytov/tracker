# Game Projects Tracker

Каталог игровых проектов из C:\proj: карточки с коротким описанием, стартовой
оценкой готовности геймплея и иконкой, созданной ImageGen с опорой на исходную
графику проекта.

## Возможности

- поиск и фильтры по платформам;
- сортировка по готовности геймплея и названию;
- карточка проекта с путём к исходной папке;
- задачи и оценка готовности, которые можно менять после входа владельца;
- общая база Supabase, используемая каталогом механик mushroomsSveta.

Проценты — ориентировочная оценка текущей сборки и материалов. Они не считаются
по числу задач и могут быть изменены владельцем из карточки проекта.

## Общая база задач

В Supabase SQL Editor выполните supabase/project-tasks.sql в том же проекте,
что и mushroomsSveta/.pages-deploy/mechanics. Функция
public.is_mechanics_owner() должна быть создана запуском
mechanics/supabase/setup.sql. Таблицы трекера закрыты RLS: читать и менять
задачи и оценки может только владелец, прошедший вход по magic link.

В Authentication → URL Configuration добавьте
https://andreyvoytov.github.io/tracker/ в список разрешённых redirect URL.
Для локального запуска добавьте http://127.0.0.1:4173/. Клиентский код
использует только publishable key; секреты Supabase в сайт не помещаются.

Первичный каталог механик уже использует тот же Supabase-проект. Новые таблицы
трекера отделены от его таблиц и готовы к переносу в другую базу позже.

## Публикация

GitHub Actions публикует содержимое site/ в GitHub Pages при обновлении ветки
main. После первого запуска workflow проверьте, что в Settings → Pages выбран
источник GitHub Actions.

## Каталог

Список проектов и стартовые проценты находятся в site/projects.js. Новые
иконки лежат в site/assets/icons/.
