# Game Projects Tracker

Каталог игровых проектов из C:\proj: карточки с коротким описанием, стартовой
оценкой готовности геймплея и иконкой, созданной ImageGen с опорой на исходную
графику проекта.

## Возможности

- поиск и фильтры по платформам;
- сортировка по готовности геймплея и названию;
- карточка проекта с путём к исходной папке;
- задачи, карточки, обложки и оценка готовности, которые можно менять без входа;
- общая база Supabase, используемая каталогом механик mushroomsSveta.

Проценты — ориентировочная оценка текущей сборки и материалов. Они не считаются
по числу задач и могут быть изменены из карточки проекта.

## Общая база задач

В Supabase SQL Editor выполните supabase/project-tasks.sql и
supabase/project-catalog.sql в том же проекте, что и
mushroomsSveta/.pages-deploy/mechanics. Скрипты можно применять повторно:
они заменяют старые политики владельца на доступ без авторизации к таблицам
трекера и загрузке обложек в project-tracker-assets. RLS остаётся включённым;
права остальных таблиц и хранилищ не меняются.

Все посетители могут редактировать трекер. Клиентский код использует только
publishable key; секреты Supabase в сайт не помещаются.

Первичный каталог механик уже использует тот же Supabase-проект. Новые таблицы
трекера отделены от его таблиц и готовы к переносу в другую базу позже.

## Публикация

Текущая версия Studio Board опубликована в Cloudflare Pages:
`https://andreyvoytov-studio-board.pages.dev`. Из корня checkout:

```powershell
npm.cmd exec --yes --package=wrangler@4.151.0 -- wrangler pages deploy site --project-name andreyvoytov-studio-board --branch main
```

Для предварительной проверки используйте отдельную preview-ветку вместо `main`.

Перед первой публикацией включите GitHub Pages в Settings → Pages и выберите
GitHub Actions как источник сборки. GitHub ограничил автоматическое включение
Pages для токена workflow. После этой настройки Actions будет публиковать
содержимое site/ при каждом обновлении ветки main.

## Каталог

Список проектов и стартовые проценты находятся в site/projects.js. Новые
иконки лежат в site/assets/icons/.

`trakt-sudeb-3d` — отдельная перспективная версия Тракта Судеб из
`C:\proj\trakt_sudeb_3d`. Подготовленная статическая сборка `out/` публикуется
через `tools/cloudflare/deploy-trakt-sudeb-3d.ps1` в отдельный Pages-проект.
`node tools/cloudflare/register-trakt-sudeb-3d.mjs` сохраняет только её карточку
в общей базе, не заменяя исходную RPG и существующие оценки готовности.

Новый проект добавляется и в `site/projects.js`, и отдельной записью в
`project_tracker_projects`: база переопределяет поля только у известных сайту
идентификаторов. Индивидуальная оценка хранится в `project_tracker_progress`.

Карточка `my-little-universe-hollow` хранит отдельную веб-версию My Little Universe
в рисованном мрачном стиле. Исходный проект остаётся в `C:\proj\My_Little_Universe`;
сборка живёт в отдельной ветке и публикуется в Cloudflare Pages командой
`tools/cloudflare/deploy-hollow.ps1`. Исходная карточка `my-little-universe`
сохраняется отдельно.
